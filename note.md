# Конспект

Математическое представление функции

`y = f(x)`

`f` - имя функции \
`x` - аргумент функции \
`y` - результат функции 

Функция - это набор команд, который мы можем выполнить

Функция может делать что-либо конкретное. Постоянно


Мясорубка - делает фарш
Какое мясо?
Такой и фарш

cat - печатает файлы на экран
Какой файл?
Такое и содержимое на экране

argc - argument counter - счётчик аргументов
argv - argument vector - вектор (набор) аргументов
argv[0] - первый аргумент
argv[1] - второй аргумент
